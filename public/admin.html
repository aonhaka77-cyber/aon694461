정적 호스팅 안내

GitHub Pages는 정적 사이트 호스팅이라 여기서 CSS를 저장하거나 이미지를 업로드할 수 없습니다. 편집 기능은 Node.js 서버에서만 동작합니다.

사이트 파일을 바꾸려면 Aon GitHub 저장소에서 수정한 뒤 저장소에 반영해 주세요. 현재 문서는 Aon 문서 파일입니다.
