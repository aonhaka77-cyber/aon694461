최근 수정: 문서 디자인 편집

1. 개요

Aon은 아이디어와 취향을 기록하고 나누기 위한 개인 공간입니다. 이곳에는 Aon의 소개와 이미지, 앞으로 더해질 이야기들이 정리됩니다.

이 사이트는 직접 관리하는 작은 위키처럼 운영됩니다. 편집 권한이 있는 사용자는 사이트 편집 메뉴에서 이미지를 추가하고 페이지의 CSS 디자인을 바꿀 수 있습니다.

2. 주요 기능

  • 방문자에게 공개되는 Aon 소개 페이지
  • 편집 화면에서 이미지 업로드 및 갤러리 게시
  • CSS 편집으로 페이지 분위기와 배치 변경

3. 이미지 모음

편집 화면에서 등록된 이미지는 이 문서를 방문하는 사람에게도 표시됩니다.

아직 등록된 이미지가 없습니다.
