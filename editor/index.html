사이트 편집

편집 키로 로그인한 뒤 이미지와 사이트 디자인을 관리할 수 있습니다.

정적 호스팅 안내

GitHub Pages는 정적 사이트라 여기서 직접 저장할 수 없습니다. PC에서 run.bat으로 Node.js 서버를 실행하면 문서, CSS, 이미지 편집 및 GitHub 게시를 사용할 수 있습니다.

게시 기능을 사용하려면 PC의 프로젝트 폴더에서 GitHub API 토큰을 비밀로 설정한 뒤 로컬 편집 화면에 접속하세요. 자세한 설정은 Aon 저장소 안내를 확인할 수 있습니다.

편집자 로그인

이미지 등록

JPG, PNG, GIF, WebP, AVIF 이미지(최대 8MB)를 올리세요. 업로드한 뒤 본문에서 넣을 위치를 정할 수 있습니다.

Aon 위키 문서

위키 문법으로 문서를 작성하세요. 이미지를 표시할 위치에 커서를 두고 {이미지} 삽입 버튼을 누르면 이미지가 연결됩니다.

== 제목 == 문단 제목 '''굵게''' 굵은 글씨 ''기울임'' 기울임 [[표시 문구|https://주소]] 링크 * 항목 글머리 목록 # 항목 번호 목록

본문에 적힌 {이미지} 순서와 연결된 이미지 순서가 일치해야 저장할 수 있습니다.

사이트 CSS

변경 사항은 PC의 SQLite에 저장됩니다. GitHub Pages 방문자에게 반영하려면 아래에서 GitHub에 게시하세요. 최대 50,000자입니다.

GitHub Pages에 게시

SQLite 문서와 CSS, 업로드 이미지를 저장소에 정적 파일로 게시합니다. Actions 배포가 끝나면 방문자에게 공개됩니다. GitHub API 키는 서버의 .env에만 보관됩니다.
